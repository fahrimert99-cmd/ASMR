- Numaralandırma kesintisiz: 001–059 arasında eksik yok.
- `044` dosya adında sosyal medya kaynaklı uzun bir sayı eki taşıyor
  (`..._801284266_1716358366084459_...`). İçerik doğru, yalnızca isim
  deseni diğerlerinden farklı. İstenirse desene uydurulabilir.
- Bu set beslenme kanalı içerikleriyle **ilgisizdir**; senaryo ve prompt
  dosyaları `prompts/beslenme-bilim-kanali/` altındadır.
